# Landing Page Performance & Intent Matrix Dashboard

An end-to-end Looker Studio documentation guide designed to track, analyze, and surface user landing page intent, channel attribution, and funnel conversion performance for GA4 e-commerce platforms.

### Methodology & Strategic Context

* **The UA vs. GA4 Metric Pivot:** This architecture uses Universal Analytics (UA) single-page exit principles to solve GA4's native ambiguity around time-on-page timers. It evaluates traffic strictly on a session level: **Did the landing session advance into the e-commerce funnel, or did it drop off without taking action?**
* **PDP-to-Cart Funnel Logic (80% Traffic Allocation):** For e-commerce stores where ~80% of acquisition traffic lands directly on Product Detail Pages (PDPs), evaluating landing performance requires tracking transactional intent. This model measures whether a landing session successfully converted into an **Add to Cart** or **Purchase** step.
* **Paid Media Campaign Diagnostic:** By measuring immediate session drop-off before the Add to Cart step, this framework gives media buyers an instant diagnostic tool within 24–48 hours of launching a campaign. Seeing a **70% vs. 20% landing-to-cart drop-off** immediately isolates whether campaign performance issues stem from ad-to-landing relevance versus downstream pricing or checkout friction.
* **Cross-Sell & Gateway Flow Mapping:** Evaluates non-linear user journeys where landing paths differ from converted SKUs. By tracking cross-sell behavior through custom Sankey flows and behavior classifications, it highlights top-performing gateway entry points and product affinity networks.

## Data Model & Metric Definitions (Dual-Layer Architecture)

To resolve cross-shopping edge cases (e.g., landing on Product A but purchasing Product Y, or landing on Homepage and buying Product Z), the dashboard uses a tri-layer data architecture separating **Macro Acquisition**, **Micro PDP Merchandising**, and **Product Purchase Flow**.

### Page 1: Macro Acquisition View (Session-Level Model)
Evaluates whether a landing page path successfully attracted and converted a customer for the business, regardless of cross-shopping movement.

* **Intent Bounce Rate:** A session starting on a landing path with **no primary engagement action** on that initial lander (`add_to_cart = 0` / `select_item = 0`). High bounce rates alongside high RPS highlight successful "pass-through" entry paths.
* **Session Conversion Rate (Conversion Rate):** Percentage of entry sessions landing on this path that resulted in **any site purchase** (`had_purchase = 1`).
* **Revenue Per Session (RPS):** Total downstream business revenue generated by sessions originating on this landing path.
* **Revenue Per Engaged Session:** Revenue divided strictly by sessions that met landing intent requirements (calculates as £0/NULL for unengaged pass-through sessions).

### Page 2: Micro PDP Diagnostic (Item/SKU-Level Model)
Evaluates whether a specific Product Detail Page (PDP) successfully convinced the user to interact with and purchase **its own inventory**. Built using hit-level unnested arrays (`items.item_id` / `items.item_name`).

* **PDP Bounced Sessions:** A PDP entry session where **the landing product SKU specifically** was NOT added to cart (`had_sku_add_to_cart = 0`).
* **PDP Bounce Rate:** Percentage of PDP entry sessions that failed to generate an `add_to_cart` for the landing product SKU.
* **Add to Cart Rate:** Percentage of PDP entry sessions where the landing product SKU was added to cart.
* **PDP SKU Conversion Rate:** Percentage of PDP entry sessions that resulted in a purchase of **that exact landing product SKU**.

### Page 3: Product Purchase Flow (Cross-Sell & Gateway Model)
Evaluates downstream SKU migration patterns from entry points to purchased SKUs. Classifies purchase intent into three distinct behavioral buckets.

* **Purchase Behavior Classification:**
  * `Direct SKU Purchase`: Entry SKU matches Purchased SKU (`entry_item_name = purchased_item_name`).
  * `Product Cross-Sell`: Session landed on a PDP (`/product/%`) but purchased a different product SKU.
  * `Gateway Entry Purchase`: Session landed on a non-PDP (Homepage `/`, Collection `/collections/`, Info `/about`) and converted on a product SKU.
* **Cross-Sell Revenue:** Sum of `attributed_revenue` derived exclusively from `Product Cross-Sell` and `Gateway Entry Purchase` flows.
* **Gateway Cross-Sell Rate (%):** Percentage of total attributed revenue driven by cross-sell/gateway paths versus direct purchases.

### Page 4: Paid Media Appendix
Provides granular campaign, source/medium, and channel performance breakdowns for paid acquisition channels.

## Data Studio Calculated Fields Suite

### 1. Custom Channel Grouping (Calculated Dimension for Page 1 & Page 3)
Add a **Calculated Field** named `Channel Grouping`:

```sql
CASE 
  WHEN REGEXP_MATCH(LOWER(medium), '^(cpc|ppc|paidsearch)$') THEN 'Paid Search'
  WHEN REGEXP_MATCH(LOWER(medium), '^(paidsocial|paid_social|meta_paid|social_paid)$') THEN 'Paid Social'
  WHEN LOWER(medium) = 'organic' THEN 'Organic Search'
  WHEN REGEXP_MATCH(LOWER(medium), '^(organicsocial|organic_social|social)$') THEN 'Organic Social'
  WHEN LOWER(medium) = 'referral' THEN 'Referral'
  WHEN REGEXP_MATCH(LOWER(medium), '^(email|newsletter)$') THEN 'Email'
  WHEN LOWER(medium) = 'affiliate' THEN 'Affiliates'
  WHEN (source IS NULL OR source = '(direct)' OR source = '(not set)') AND (medium IS NULL OR medium = '(none)' OR medium = '(not set)') THEN 'Direct'
  ELSE 'Unassigned'
END
```

## 📊 Looker Studio Chart Configuration

### 1. Executive KPI Scorecards
* **Metrics:** `Total Sessions`, `Page Engagement Rate`, `Total Revenue`, `Revenue Per Engaged Session`.

### 2. 30-Day Active Intent & Engagement Trend (Combo Chart)
* **X-Axis Dimension:** `event_date`
* **Series 1 (Bars):** `SUM(engaged_sessions)` mapped to **Left Y-Axis**.
* **Series 2 (Line):** `Page Engagement Rate` mapped to **Right Y-Axis** *(Set Right Axis Max to 1.0 / 100%)*.

### 3. Landing Page Performance Table (Drill-Down Setup)
* **Dimensions:**
  1. `Page Type` (Top Level)
  2. `Landing Page` (Sub-Level)
* **Drill-Down Switch:** Enabled.
* **Default Drill-Down Level:** Set to `Page Type`.
* **Chart Header:** Set to **Always Show** to display drill-down arrows.

### 4. Interactive Filters Controls
Add the following Drop-down controls at the top of the report:
* `Channel Grouping`
* `Source / Medium`
* `Device Category`
